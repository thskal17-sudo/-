# 1:1 ZOOM 컨설팅 모집 자료

| 파일 | 용도 |
|---|---|
| `thumb_wide.png` | 가로형 썸네일, 2400×1260 (1200×630 비율). 홈페이지 배너, 링크 미리보기 |
| `thumb_square.png` | 정사각형 썸네일, 2160×2160 (1080×1080 비율). 게시판 목록, SNS |
| `google_form.gs` | 구글폼 신청서와 응답 시트를 한 번에 만드는 Apps Script |
| `thumbnail.html` | 썸네일 원본. 문구를 고친 뒤 다시 렌더하면 된다 |
| `render.cjs` | 썸네일 PNG 렌더 스크립트 |

## 구글폼 만들기

1. https://script.google.com 에서 [새 프로젝트]를 연다.
2. 기본 코드를 지우고 `google_form.gs` 내용을 붙여넣는다.
3. 맨 위 `SETTINGS` 에 일정·인원·비용·운영 주체를 채운다. 비워 두면 그 줄은 빠진다.
4. 함수 `createConsultingForm` 을 골라 [실행]하고 권한을 허용한다.
5. 실행 로그에 나온 **응답 링크**를 홈페이지 게시글과 [신청하기] 버튼에 붙인다.

응답은 함께 만들어지는 구글 시트 "1:1 ZOOM 컨설팅 신청자 명단"에 쌓인다.

### 신청서 문항

1. **기본 정보**: 성함, 휴대폰 번호(형식 검사), 이메일(형식 검사)
2. **활동·지원 분야**: 분야(복수 선택), 주 강의 주제, 강사 경력
3. **고민**: 고민되는 부분(복수 선택), 상담 때 이야기하고 싶은 내용(선택)
4. **희망 일정**: 가능 요일, 가능 시간대, ZOOM 사용 경험, 알게 된 경로(선택)
5. **개인정보 수집·이용 동의** (필수)

## 썸네일 다시 만들기

`thumbnail.html` 의 문구를 고친 뒤 저장소 루트에서 실행한다.

```bash
node promo/zoom-consulting/render.cjs
```
