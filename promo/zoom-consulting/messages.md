# 신청자 안내 문자

[ ] 안의 내용만 바꿔서 보낸다. 신청자 정보는 신청자 명단 시트에서 확인한다.

## ① 신청 확인 + 상담 시각·ZOOM 링크 (신청 들어오면 바로)

```
[평생교육원 지원서 1:1 ZOOM 컨설팅]
[성함] 강사님, 신청해 주셔서 감사합니다 😊

▶ 상담 일시: 11월 10일(화) [19:00 ~ 19:20]
▶ ZOOM 링크: [ZOOM 링크]
▶ 회의 ID: [회의 ID] / 암호: [암호]

■ 준비해 주세요
- 작성 중인 지원서 파일 (화면 공유로 함께 봐요)
- 지원하려는 기관의 모집 공고 (있으시면)
- 5분 전에 미리 접속해 주세요

시간 변경이 필요하시면 이 번호로 편하게 연락 주세요.
```

## ② ZOOM이 처음인 분께 덧붙이기 ("처음이에요"를 고른 분)

```
■ ZOOM 접속 방법
- 휴대폰: 앱스토어/플레이스토어에서 'ZOOM Workplace' 설치 → 링크 누르기
- 컴퓨터: 링크 누르기 → '브라우저에서 참가' 또는 프로그램 설치
- 이름은 실명으로 입력해 주세요 (대기실에서 확인 후 입장시켜 드려요)
- 지원서를 함께 보려면 컴퓨터로 접속하시는 게 편해요
```

## 보낼 때 참고

- 한글 45자가 넘으면 장문 문자(LMS)로 나간다. ①②는 장문이니 한 번에 이어 붙여 보내도 된다.
- ZOOM 무료 계정은 회의 한 번이 40분에서 끊긴다. 5명을 한 링크로 이어서 받으면(19:00~20:40) 중간에 끊기니, 무료 계정이면 **한 분마다 회의를 따로 만들어** 각자 다른 링크를 보낸다. 유료 계정이면 한 링크에 대기실을 켜 두고 한 분씩 입장시켜도 된다.
- 이메일로도 보낼 때는 같은 문구에 제목 `[평생교육원 지원서 컨설팅] 11/10 상담 시각과 ZOOM 링크 안내` 를 붙인다.
