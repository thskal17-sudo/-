# 직업인 체험 강사 모집 구글 폼 만들기

`career-day-instructor-form.gs` 를 실행하면 구글 폼이 내 구글 드라이브에 자동으로 생깁니다.
파일 업로드 질문만 구글 정책상 스크립트로 만들 수 없어서, 마지막에 직접 한 번 추가하면 됩니다.

## 1. 폼 만들기 (약 3분)

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본으로 들어 있는 코드를 지우고 `career-day-instructor-form.gs` 내용을 전부 붙여 넣기 → 저장(Ctrl+S)
3. 위쪽 함수 선택 칸에서 `createCareerDayForm` 선택 → **실행**
4. 처음 한 번은 권한 요청이 나옵니다 → **권한 검토** → 내 계정 선택 → **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
5. 아래 **실행 로그**에 나온 **폼 편집 링크**를 엽니다.

> 날짜·시간·강사료를 바꾸려면 코드 맨 위 `EVENT_DATE`, `EVENT_TIME`, `FEE_PER_HOUR`, `SESSIONS` 만 고치고 다시 실행하세요.
> 다시 실행하면 폼이 **새로** 하나 더 만들어지니, 이전 폼은 드라이브에서 지우면 됩니다.

## 2. 파일 업로드 질문 추가

편집 화면에서 **3. 수업 계획** 섹션의 마지막 질문을 클릭한 뒤 오른쪽 **+(질문 추가)** → 질문 유형을 **파일 업로드**로 바꾸고 아래처럼 설정합니다.

| 설정 | 값 |
|---|---|
| 질문 | 이력서 / 경력 증빙 / 강의계획서 제출 |
| 설명 | 이력서, 자격증 사본, 강의계획서 등 (최대 5개) |
| 특정 파일 형식만 허용 | 켜기 → 문서, PDF, 이미지, 프레젠테이션 |
| 최대 파일 수 | 5 |
| 최대 파일 크기 | 10MB |
| 필수 | 선택 (필수로 하려면 켜기) |

**알아둘 점**
- 파일 업로드 질문이 있으면 응답자는 **구글 계정으로 로그인**해야 신청할 수 있습니다.
- 올라온 파일은 폼 만든 사람의 구글 드라이브(폼 이름 폴더)에 저장됩니다.

## 3. 배포

편집 화면 오른쪽 위 **보내기** → 링크 아이콘 → **URL 단축** → 복사해서 공유합니다.
응답은 **응답** 탭 → **Sheets에 연결**로 스프레드시트에서 모아 볼 수 있습니다.

## 폼 구성

| 섹션 | 질문 |
|---|---|
| 안내문 | 일시, 장소, 이론+체험 2차시, 학급당 26~28명, 강사료 시간당 5만원 × 2차시 = 10만원, 현직 우선 |
| 1. 기본 정보 | 성함, 연락처(형식 검사), 이메일(형식 검사), 직업/소속, 현직 여부 |
| 2. 희망 직업군 | 학년별 직업군 체크박스(복수 선택·기타), 경력 사항, 학생 대상 강의 경험 |
| 3. 수업 계획 | 이론 내용, 체험 내용, 준비물/재료비, 필요 시설·기자재, **파일 업로드(직접 추가)** |
| 4. 일정 확인 및 동의 | 참여 가능 여부, 강사료 확인, 개인정보 수집·이용 동의, 기타 문의 |
