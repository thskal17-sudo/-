# 직업인 체험 강사 모집 구글 폼 만들기

흐름: **강사가 안내문에 첨부된 한글 양식을 작성 → 폼에서 업로드 → 담당자가 드라이브에서 한꺼번에 내려받아 확인**

`career-day-instructor-form.gs` 를 실행하면 구글 폼이 내 구글 드라이브에 자동으로 생깁니다.
파일 업로드 질문만 구글 정책상 스크립트로 만들 수 없어서, 마지막에 직접 한 번 추가하면 됩니다.

## 1. 폼 만들기 (약 3분)

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 코드를 지우고 `career-day-instructor-form.gs` 내용을 전부 붙여 넣고 저장(Ctrl+S)
3. 함수 선택 칸에서 `createCareerDayForm` 선택 → **실행**
4. 처음 한 번은 권한 요청이 나옵니다 → **권한 검토** → 내 계정 → **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
5. 아래 **실행 로그**의 **폼 편집 링크**를 엽니다.

> 날짜·시간·강사료는 코드 맨 위 `EVENT_DATE`, `EVENT_TIME`, `FEE_PER_HOUR`, `SESSIONS` 를 고치고 다시 실행하세요.
> 다시 실행하면 폼이 **새로** 하나 더 생기니, 이전 폼은 드라이브에서 지우면 됩니다.

## 2. 파일 업로드 질문 추가

편집 화면에서 **3. 서류 제출** 섹션 제목을 클릭 → 오른쪽 **+(질문 추가)** → 유형을 **파일 업로드**로 바꾸고 아래처럼 설정합니다.

| 설정 | 값 |
|---|---|
| 질문 | 작성한 서류 업로드 |
| 설명 | 첨부파일 확인하여 업로드해주세요. (한글 파일 + 신분증·통장사본·자격증 사진/PDF) |
| 특정 파일 형식만 허용 | **끄기** (켜면 한글 .hwp 파일이 막힐 수 있음) |
| 최대 파일 수 | 5 |
| 최대 파일 크기 | 10MB |
| 필수 | **켜기** |

**알아둘 점**
- 구글 드라이브는 한글(.hwp) 파일을 미리보기로 열지 못합니다. 업로드는 정상적으로 되니, 내려받아 한글 프로그램으로 열면 됩니다.
- 파일 업로드 질문이 있으면 지원자는 **구글 계정으로 로그인**해야 신청할 수 있습니다.
- 제출 서류에는 신분증·통장사본이 들어 있습니다. 업로드 폴더는 다른 사람과 공유하지 마세요.

## 3. 배포

편집 화면 오른쪽 위 **보내기** → 링크 아이콘 → **URL 단축** → 복사해서 공유합니다.

## 4. 제출 서류 내려받기

**한꺼번에 받기**
1. 폼 편집 화면 → **응답** 탭 → **질문** 보기 → "작성한 서류 업로드" 질문 선택 → **폴더 보기**
   (또는 드라이브에서 `[폼 이름] (File responses)` 폴더)
2. 폴더 안 파일을 모두 선택(Ctrl+A) → 오른쪽 클릭 → **다운로드** → ZIP 으로 받아집니다.

업로드된 파일 이름 뒤에는 지원자 이름(구글 계정 이름)이 붙어 누가 낸 것인지 구분됩니다.

**지원자별로 보기**
- **응답** 탭 → **개별 보기**: 한 사람씩 입력 내용과 파일을 함께 봅니다.
- **응답** 탭 → **Sheets에 연결**: 지원자 한 줄마다 성함·연락처·희망 직업군과 업로드 파일 링크가 정리됩니다.
