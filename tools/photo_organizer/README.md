# MYBOX 사진 정리 도구

네이버 MYBOX에서 받은 아이폰 사진(라이브포토 압축 포함)을 촬영 날짜별로 정리한다.
**원본 폴더는 읽기만 하고**, 결과는 모두 결과 폴더에 복사본으로 만든다.

## 준비 (Windows)

```bat
pip install pillow pillow-heif
```

## 순서

```bat
:: 1) 요약만 보기 (아무것도 쓰지 않음)
python photo_organizer.py scan "D:\2026년 활동사진\MYBOX"

:: 2) 정리 (정리된사진, 정리기록.csv, _검토용 모아보기 생성)
python photo_organizer.py organize "D:\2026년 활동사진\MYBOX" "D:\2026년 활동사진\정리결과"

:: 3) _검토용\모아보기_XX.jpg 를 보고 _검토용\판정입력.csv 의 '판정' 칸에
::    교실 / 확인필요 / 아님 중 하나를 적은 뒤
python photo_organizer.py classroom "D:\2026년 활동사진\정리결과"

:: 4) 월별 장수·판정 집계
python photo_organizer.py report "D:\2026년 활동사진\정리결과"
```

## 결과 구조

```
정리결과\
  정리된사진\2025\2025-12\2025-12-16_10-15-30.jpg   (+ 같은 이름 .mov = 라이브포토 영상)
  정리된사진\중복사진\       내용이 완전히 같은 사진의 나머지
  정리된사진\날짜없음\       촬영 날짜도, 파일 이름 날짜도 없는 이미지(스크린샷 등)
  교실사진\2025\2025-12\     판정 '교실' (영상도 함께 복사)
  교실사진\확인필요\         판정 '확인필요'
  정리기록.csv              원본 → 새 위치, 촬영날짜, 날짜출처, 판정
  _검토용\                  판정용 모아보기·판정입력.csv (다 끝나면 지워도 됨)
```

## 규칙

- 날짜: EXIF 촬영 날짜(DateTimeOriginal) → 없으면 파일 이름 속 날짜(`P20251216_101530196…`,
  `IMG_20251216_101530`, `Screenshot_20251203-121500` 등) → 없으면 `날짜없음`.
  파일 수정 날짜(다운로드 날짜)는 쓰지 않는다. 파일 이름 날짜도 쓰지 않으려면 `--no-filename-date`.
- 단독 동영상은 영상 안의 촬영 시각(`com.apple.quicktime.creationdate`, 없으면 생성시각 UTC+9)을 쓴다.
- 중복: 사진 내용(바이트)의 SHA-256 이 같으면 중복. `_1`, `(1)` 같은 꼬리가 없는 쪽을 남긴다.
- HEIC → JPG(화질 92). 촬영 EXIF·ICC 색 프로필 유지, 회전은 픽셀에 한 번만 적용하고 방향 값은 1로.
  JPG/PNG 는 변환하지 않고 그대로 복사.
- 같은 초에 여러 장이면 `_2`, `_3`. 라이브포토 영상은 사진과 같은 이름.
- 압축 안 한글 이름이 UTF-8 표시가 없으면 cp949 로 읽는다.
- 결과 폴더에 이미 `정리된사진`(또는 `교실사진`)이 있으면 덮어쓰지 않고 멈춘다.
